Kebijakan privasi avf-publish

Berlaku sejak 13 November 2026.

Siapa yang memakai

avf-publish hanya dipakai oleh pemilik channel YouTube “Bedah Dulu” untuk channel miliknya sendiri. Tidak ada pengguna lain.

Data Google yang diakses

  • youtube.upload: mengunggah video milik pemilik channel ke channel itu.
  • youtube.readonly: membaca ID dan nama channel yang memberi izin, hanya untuk memastikan video diunggah ke channel yang benar.

Alat ini tidak membaca, mengubah atau menghapus video, komentar, pelanggan, analitik atau data lain di luar keperluan di atas.

Penyimpanan dan pembagian

Token akses OAuth disimpan hanya di komputer pemilik, di luar repositori kode, dan tidak dikirim ke pihak lain. Data dari Google API tidak dijual, tidak dibagikan, dan tidak dipakai untuk iklan atau melatih model AI. Catatan unggahan (ID video, URL, waktu, status privasi) disimpan lokal oleh pemilik.

Mencabut izin

Izin dapat dicabut kapan saja melalui Google Account → Keamanan → Akses pihak ketiga. Setelah dicabut, token lokal tidak berlaku dan dapat dihapus.

Penghapusan data

Token akses lokal dihapus segera setelah izin dicabut atau tidak lagi dipakai. Catatan unggahan lokal dapat dihapus kapan saja oleh pemilik; permintaan penghapusan dapat dikirim ke kontak di bawah dan diproses paling lambat 7 hari. Data API YouTube yang tersimpan diperbarui atau dihapus paling lambat 30 hari, sesuai Kebijakan Developer YouTube API Services.

Layanan pihak ketiga

Alat ini memakai YouTube API Services. Dengan memberi izin, pemilik tunduk pada Persyaratan Layanan YouTube dan Kebijakan Privasi Google.

avf-publish privacy policy (English)

Effective 13 November 2026. avf-publish is used only by the owner of the YouTube channel “Bedah Dulu” for that channel. It requests youtube.upload to upload the owner's videos and youtube.readonly only to confirm the authorizing channel before uploading. It does not access other YouTube or Google data. OAuth tokens are stored only on the owner's computer and are never shared. Google API data is not sold, shared, used for advertising or used to train AI models. Access can be revoked at any time at myaccount.google.com/permissions. Data deletion: the local token is deleted as soon as access is revoked or no longer needed; local upload records can be deleted at any time, and deletion requests sent to the contact below are handled within 7 days. Stored YouTube API data is refreshed or deleted within 30 days, in line with the YouTube API Services Developer Policies. Terms of use: terms.html. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy. Contact: bedahdulu@gmail.com.
