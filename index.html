avf-publish

avf-publish adalah alat internal milik pemilik channel Bedah Dulu untuk mengunggah video buatannya sendiri ke channel YouTube miliknya melalui YouTube Data API. Alat ini tidak dipakai oleh orang lain dan tidak ditawarkan sebagai layanan publik.

avf-publish is a private tool used only by the owner of the YouTube channel “Bedah Dulu” to upload the owner's own videos to the owner's own channel through the YouTube Data API. It is not offered to other users.

Uses YouTube API Services

avf-publish uses YouTube API Services (YouTube Data API v3) to upload videos to the YouTube channel Bedah Dulu. By using avf-publish, users agree to the YouTube Terms of Service. See also the Google Privacy Policy.
